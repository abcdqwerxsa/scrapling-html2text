# Cloudflare 开源了自家企业级 Agent 工作平台

**作者**: 字节笔记本
**发布时间**: 2026-08-06 08:20
**原文链接**: https://mp.weixin.qq.com/s/PgCM_5muuEcERsT6ek84gQ

---

Cloudflare 把内部用了大半年的 Cloudflare OS 开源了。

Cloudflare OS 是一个装在公司内部的 AI 工作平台，给公司团队里每个人配一个懂公司业务的 Agent 助手，外加一套能安全访问内部系统的权限体系。

说得再简单一点，这个就是企业版的Claude Work，公司把自己的业务知识、常用系统、操作流程灌进去以后，员工打开浏览器就能用自然语言让 Agent 帮忙查资料、写文档、做数据看板，甚至直接生成一个针对公司业务特定场景能用的小应用。

现在AI办公大行其道，各家大厂都在跟进，但每个家公司 每个团队的业务场景各不一样，一个通用型的Agent很难真正帮得上忙。

比如在公司内部查数据、写方案、对接系统、协调进度，首先真的懂公司的业务背景，其次得能真正对接到公司在用的系统。

Cloudflare 从今年开始就做类似的尝试，在期间遇到了很多问题。

一是当时生成的小应用是静态的。连不上真实的内部数据，很多本可以自动化的重复劳动，还是得靠人反复去问 Agent。

二是权限管理跟不上。团队开始共享工作区和产出物之后，发现光靠“控制 Agent 能调用哪些工具”是不够的，因为工具调用权限管不住 Agent 已经看到过的数据会不会被间接传给不该看到的人。

这次开源的最新版本，就是针对这两个问题重新搭的架子。

最新版本的Cloudflare OS，划分出了三个模块。

  * • **Agent 工作区** ：每个人的对话入口，自带公司整理好的业务知识和操作技能，还配了一个独立的运行环境，让 Agent 能实际写代码、跑代码。

![](https://r2.jeanjan.kdns.fr/pictures/img-741f86c501.png)

  * • **权限治理框架** ：管住 Agent 和它生成的应用到底能碰哪些内部数据，是整套系统里技术含量最高的部分。

![](https://r2.jeanjan.kdns.fr/pictures/img-741f86c502.png)

  * • **可修改小应用平台** ：不用写代码，聊几句就能让 Agent 生成一个带界面、能存数据、能和同事协作的小工具。

最终达到的效果就是，一次对话可以慢慢长成一份文档、一个应用，或者一套自动跑的工作流程。

![](https://r2.jeanjan.kdns.fr/pictures/img-741f86c503.png)

这样即使不懂代码的用户，打开浏览器就能用，常见场景包括：

  * • 让 Agent 结合公司内部资料回答问题、整理调研
  * • 把调研结果直接生成文档、幻灯片或表格，而且这些产出可以持续联动数据源，不是死文件
  * • 让 Agent 现场搭一个带界面、能存状态的小应用，团队一起用
  * • 把一套重复性工作固化成自动执行的流程，该跑代码的地方跑代码，只在需要判断的地方才调用模型

自己搭的小应用还可以分享给同事，对方要么直接进来协同用同一份数据，要么复制一份代码自己改，不用再找你提需求排期。

**具体怎么用呢？**

可以先通过它的源码在本地进行尝试，先看看这东西长什么样、体验一下再决定要不要认真部署。

步骤是这样：

  * • 准备一个 Cloudflare 账号，本地装好 pnpm
  * • 把 GitHub 上的 cloudflare-os 仓库拉到本地，装好依赖
  * • 用官方提供的命令跑起来，浏览器打开就能用

我们可以在原有的基原版基础上进行修改和功能，想图省事给团队里的人一起用，可以走 cloudflare-os-starter 这个仓库，这是专门为部署定制准备的示例项目，并且提供了一键式的安装链接，这套线上的部署是需要付费的订阅的，最低每月 5 刀。
