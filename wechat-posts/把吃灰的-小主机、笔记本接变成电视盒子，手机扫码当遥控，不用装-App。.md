# tinyplay

> 一个轻量级媒体播放器，能让吃灰的 Windows 小主机、笔记本或 Mac mini 接上电视就能用，手机扫码当遥控，不用装 App。

Github地址

https://github.com/YangHanqing/tinyplay

![](https://r2.jeanjan.kdns.fr/pictures/img-acb9674001.png)

## 功能特性

  * 手机遥控：浏览器扫码直连，不用下载东西
  * 网页浏览：电视上直接看 YouTube、Netflix，不用键盘鼠标
  * 媒体库：连 Emby、Jellyfin、Plex，海报墙、追剧、续播都有
  * 文件播放：SMB、WebDAV 共享盘或者本地文件夹，点哪播哪
  * 电视直播：IPTV 频道列表，能收藏、有历史记录
  * DLNA 投屏：局域网内其他 App 投过来，手机还能继续控播放
  * 多源切换：同时挂好几个媒体源，随时换着看
  * 跨平台：Windows、macOS（含 Intel 和 Apple Silicon）都能跑，另有 Apple TV 版本
  * 底层 mpv：MKV、HDR、杜比视界、TrueHD、PGS 字幕这些格式都吃得下

## 怎么用

去 GitHub Releases 下最新版：

  * Windows：跑 `TinyPlay-Setup-x64.exe`，装完自动启动，以后覆盖安装自动保留设置。Windows 可能弹 SmartScreen，因为没签名。
  * macOS：`TinyPlay-macos-arm64.dmg` 或 `TinyPlay-macos-intel.dmg`，拖进 Applications 完事。

手机和电脑得在同一个局域网。详细截图和上手引导看 官网。
