## 三、baoyu-slide-deck 到底有多强？

先用一句话定调：

> **它不是一个"套模板"的 PPT 工具，而是一个理解了你的内容之后，从零开始"创作"幻灯片的 AI 设计师。**

传统的 PPT 工具怎么做？你选一个模板，然后往里面填文字，调字体，对齐文本框，找配图……你 80% 的时间花在"怎么做"上，只有 20% 的精力留给"说什么"。

baoyu-slide-deck 把这个比例颠倒了过来。

它的工作流程分三步：
```

你给内容 → AI 设计大纲 → 你确认大纲 → AI 逐页生成图片 → 自动合成 PPTX/PDF
```

每一步都是 AI 自己完成的，你只需要在"确认大纲"那个节点上说一句"行"——然后就等着收成品。

### 它怎么理解"设计"？

这可能是最让人惊艳的部分。baoyu-slide-deck 不是简单地给文字加个背景，它真的在"设计"。

来看一个真实的例子。我给它的内容是"2026 年度人才战略规划方案"，它自动产出了这样的大纲片段：
```

Slide 1 — 封面  
  主标题：2026 年度人才战略规划  
  副标题：以人才驱动增长，构建面向未来的组织能力  
  视觉：极简商务风格。深蓝色背景上以几何线条勾勒出一棵生长的树，  
        树冠由不同大小的圆形节点组成，象征"人才梯队"。  
        底部一条金色细线，传递"战略高度"的质感。  
  
Slide 2 — 核心议题  
  主标题：2026，我们面临的人才挑战  
  副标题：四大核心议题，决定未来三年竞争力  
  关键数据：  
    · 关键岗位招聘周期：45天 → 急需缩短至 30 天  
    · 核心人才流失率：18.7%（行业警戒线 15%）  
    · 管理岗内部晋升占比：仅 32%  
    · 90 后/95 后员工占比已达 67%  
  视觉：四象限布局，每个象限一个议题图标+关键数字，  
        用从红色到绿色的渐变传递"挑战→目标"的叙事。  
  
Slide 3 — 数据洞察  
  主标题：人才盘点：我们的"家底"到底怎么样？  
  副标题：基于 2025 年度全员盘点数据的深度分析  
  视觉：左侧手绘风格柱状图（各职级人数分布），  
        右侧环形图（人才九宫格分布：明星/核心/待提升/观望）。  
        关键数字用超大字号强调，配色克制——只用深蓝+金色。
```

注意到了吗？它不仅列出了"该放什么文字"，它设计了一个**叙事弧线** ——从封面的"战略定调"到核心议题的"制造紧迫感"，到数据分析的"直面问题"，再到后续方案的"给出解法"，最后到封底的"行动号召"。

而且，每一页的视觉设计都在服务于叙事目标。封面用生长的树传递"人才培育"理念，挑战页用四象限+红绿渐变制造"危机感→希望感"的张力，数据页用超大字号把关键数字钉进观众脑子里……

**这已经不是在"做 PPT"了，这是在"讲述一个故事"。**

###  四种场景，四种打法

baoyu-slide-deck 最让我服气的一点是：它会根据场景自动调整"讲故事的策略"。同样是一个"方案"，不同场景下的叙事逻辑完全不同：

**场景一：年度述职报告**

你是一个 HR 经理，要在年终会上汇报全年工作。AI 给你的叙事策略是"**从成果到价值** "——先亮出全年 KPI 完成情况（新人留存率提升 12%、招聘周期缩短 8 天），再用具体项目案例佐证，最后落到"这些成果为公司省了多少钱/创造了什么价值"。封面用 `corporate` 风，数据页干净利落，案例页配人物插画增加温度。

**场景二：投资人路演方案**

你要拿下一轮融资，讲的是"我们为什么是最值得投的团队"。AI 给你的叙事策略是"**问题→方案→验证→愿景** "——先让投资人感受到市场的痛点有多痛，再亮出你的方案为什么比别人好，用数据证明已经跑通，最后画一张足够大的饼。封面用 `bold-editorial` 风，大字报式排版，视觉冲击力拉满。

**场景三：内部项目提案**

你要说服管理层给一个新项目批预算。AI 给你的叙事策略是"**现状→机会→方案→投入产出比** "——不卖关子，不堆形容词，每一页都在回答管理层最关心的一句话："花这笔钱，能赚回来多少？"封面用 `minimal` 风，极简克制，每一个像素都在说"我很专业，没有废话"。

**场景四：培训课程 / 文化宣讲**

你要给新员工讲企业文化，或者给团队做一次能力培训。AI 给你的叙事策略是"**共鸣→认知→行动** "——先用一个所有人都经历过的场景制造共鸣，再拆解背后的逻辑，最后给出"明天就能用"的实操方法。封面用 `sketch-notes` 或 `chalkboard` 风，手绘风格让人觉得"这不是在上课，是一个前辈在跟你聊天"。

### 16 种视觉风格，每种都是一套完整的设计语言

baoyu-slide-deck 支持 16 种风格预设。但别被"预设"这个词骗了——每种风格都是一套完整的设计语言，包含配色方案、字体策略、视觉元素风格、排版密度四个维度的完整定义。

| 风格                      | 适合场景       | 一句话画面感                     |
|-------------------------|------------|----------------------------|
| `corporate`             | 战略方案、投资人路演 | 像麦肯锡出品的咨询报告，数据图表清晰，专业感溢出屏幕 |
| `minimal`               | 高管简报、项目提案  | 每页只放最关键的一句话，留白是最大的设计       |
| `bold-editorial`        | 产品发布、品牌宣讲  | 杂志封面式大字排版，视觉冲击力强到让人挪不开眼    |
| `blueprint`             | 技术方案、系统架构  | 深蓝底白线图的工程蓝图风，架构图天生适配       |
| `sketch-notes`          | 团队分享、内部培训  | 手绘笔记风格，像资深前辈在白板上边画边讲       |
| `chalkboard`            | 新人培训、文化宣讲  | 黑板粉笔画，轻松、亲切，没有距离感          |
| `editorial-infographic` | 数据报告、行业分析  | 信息图+杂志排版，数据可视化的天花板         |

**选对风格，等于选对了观众打开 PPT 前三秒的心理预期。** 给 CEO 汇报用 `corporate`，给团队做分享用 `sketch-notes`，给投资人路演用 `bold-editorial`。别小看这个选择——它决定了观众是"认真听"还是"刷手机"。

## 四、从零到一，实操全流程

好了，说了这么多"它有多厉害"，我们来看看具体怎么用。我保证你 10 分钟就能上手。

### 第 0 步：安装（一次性）
```

npx skills add jimliu/baoyu-skills
```

22 个技能一次性装好。不需要单独安装某个技能，不需要配环境变量——除了如果你要发公众号需要配 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET`，但单纯做 PPT 不需要任何额外配置。

### 第 1 步：准备内容

baoyu-slide-deck 吃的是 Markdown。所以你需要先把你的内容整理成 Markdown 格式。

如果你手头只有一个 Word 文档，或者一个网页链接，甚至只是一堆散乱的笔记，有办法：
```

# 把网页素材转成 Markdown  
/baoyu-url-to-markdown https://example.com/industry-report-2026  
  
# 让 AI 帮你整理零散素材  
"这是我去年的工作周报和项目邮件，帮我提炼出一份 12 页的年终述职 PPT 大纲，  
包含：全年 KPI 完成情况、重点项目回顾、团队建设成果、明年规划。  
每页标注标题和 3 个关键数据点。Markdown 格式。"
```

如果你连素材都没有——直接让 Claude 帮你从头构建。比如你需要出一份"Q3 市场推广方案"：

> "我在一家 SaaS 公司做市场总监，公司产品是面向中大型企业的智能客服系统。帮我写一份 Q3 市场推广方案的 PPT 大纲，12 页，包含：市场现状与竞品格局、目标客户画像、推广策略（内容营销+行业峰会+渠道合作）、预算分配、ROI 预测、时间线。每页标注标题、核心观点和关键数据。语言简洁有力，不要官方套话。"

**关键技巧** ：在这个阶段，把你脑子里的"隐性知识"全部倒给 AI。你知道的行业常识、公司背景、老板偏好——AI 不知道。你给的上下文越丰富，它产出的方案就越像是"你自己写的"而不是"AI 代笔的"。

### 第 2 步：一键生成
```

/baoyu-slide-deck Q3市场推广方案.md --slides 12 --style corporate --audience executives --lang zh
```

然后 AI 会先输出大纲让你确认。这个环节**千万不要跳** ——大纲阶段是你最好的修改窗口。仔细检查逻辑是否自洽、信息密度是否合理、有没有你特别想强调但漏掉的点。

确认没问题，说一句"继续"。它就开始逐页生成了。

生成过程你会看到这样的输出：
```

[1/12] 生成封面... ✅  
[2/12] 市场格局与竞品分析... ✅  
[3/12] 目标客户画像... ✅  
...  
[12/12] 下一步行动... ✅  
  
正在合并为 PPTX...  
正在转换为 PDF...  
  
完成！生成文件：  
  📄 Q3市场推广方案.pptx  
  📄 Q3市场推广方案.pdf
```

整个过程大约 5-10 分钟。这期间你可以去泡杯咖啡、构思一下演讲的开场白，或者练习在 CEO 提问时保持表情管理。

### 第 3 步：微调（如果有必要）

生成完不是终点，更像是"初稿"交到你手里。如果你对某一页不满意：
```

# 单独重新生成第 5 页  
/baoyu-slide-deck Q3市场推广方案.md --regenerate 5  
  
# 换一种风格——比如明天要给投资人了，从 corporate 换成 bold-editorial  
/baoyu-slide-deck Q3市场推广方案.md --style bold-editorial
```

还有几个实用小技巧：

| 需求                  | 做法                                             |
|---------------------|------------------------------------------------|
| 只想看大纲，先不烧图片（省时间省成本） | `--outline-only`                               |
| 面向老板汇报 vs 面向团队分享    | `--audience executives` / `--audience general` |
| 控制信息密度              | 在 Markdown 里每页只写 3 个 bullet point              |
| 想要数据可视化             | 在 Markdown 里明确写出"这部分用柱状图对比"                    |
| 中英文混杂内容             | 声明语言即可，它自动处理双语排版                               |

## 五、不只是 PPT：baoyu skills 的完整工作流

如果你以为 baoyu-slide-deck 只是一个"做 PPT 的工具"，那你只看到了冰山一角。

把它放进 baoyu skills 的完整生态里，你得到的是一条**内容生产流水线** ：
```

素材采集 → 内容整理 → 配图生成 → 幻灯片制作 → 封面设计 → 多平台发布
```

![](https://r2.jeanjan.kdns.fr/pictures/img-30fb4f6b04.jpeg)

举个例子。假设你要做一份"2026 年 AI 行业人才趋势报告"，面向公司内部和行业社群发布：

  1. 1\. **搜集素材** ：`/baoyu-url-to-markdown` 批量抓取几篇行业研报、头部公司财报中的人才相关章节
  2. 2\. **撰写内容** ：让 Claude 基于素材写一份 5000 字的分析报告，Markdown 格式
  3. 3\. **生成封面** ：`/baoyu-cover-image` 生成一张 16:9 的报告封面图，"2026 AI 人才趋势报告"大标题+数据感背景
  4. 4\. **生成配图** ：`/baoyu-article-illustrator` 扫描全文，自动在"薪酬涨幅对比""热门岗位分布"等段落插入配图
  5. 5\. **生成信息图** ：`/baoyu-infographic` 把"AI 人才供需比""五大热门岗位薪酬区间"等核心数据做成一页页专业信息图
  6. 6\. **生成 PPT** ：`/baoyu-slide-deck` 把报告核心内容转成 15 页演讲级幻灯片，`corporate` 风
  7. 7\. **发布公众号** ：`/baoyu-post-to-wechat` 把完整报告推送到公众号草稿箱
  8. 8\. **分发小红书** ：`/baoyu-xhs-images` 自动把报告拆成 6-8 张小红书图文卡片，适配竖屏阅读
  9. 9\. **同步微博/X** ：`/baoyu-post-to-weibo` 和 `/baoyu-post-to-x` 提取核心观点+封面图，一键发布

**一份行业报告，变成了：一套演讲 PPT + 一篇公众号长文 + 一组小红书卡片 + 两条社交媒体动态。**

你写了一份内容，却拥有了一套全平台的内容矩阵。这就是 baoyu skills 真正的威力——它不解决"某一个"问题，它解决"一整条链路"的问题。

## 六、我踩过的坑，你不用再踩

用了两个月的 baoyu skills，做过的 PPT 从高管述职到产品发布会到新人培训课件，总结了几个血泪经验：

### 1\. 内容质量决定 PPT 质量——AI 不会替你思考

这是最重要的原则，没有之一。AI 可以帮你设计、排版、配图、甚至构建叙事弧线，但如果你给它的内容空洞无物——全是"赋能""抓手""闭环"这种正确的废话——它还给你的也只能是一堆排版精美的废话。

**输入时多花 10 分钟打磨你的核心观点和数据，等于输出时省下 2 小时的修改时间。** AI 是放大器，它放大的是你输入的质量，不管是好的还是坏的。

### 2\. 大纲阶段是你最后的"低成本修改窗口"

一旦图片生成了，要改内容就意味着重新生成——时间成本从 30 秒变成 1 分钟。所以在大纲阶段，一定要像审合同一样仔细：

  * • 逻辑链有没有断？"因为 A 所以 B 所以 C"每一步都成立吗？
  * • 每一页的信息量合适吗？如果一页有 8 个 bullet point，拆成两页。
  * • 老板最关心的那个问题，有没有一页专门回答？

**在大纲阶段花 5 分钟仔细审，能省下后面 50 分钟的推倒重来。**

###  3\. 中文字体偶尔会翻车——这是生图模型的通病

AI 生图模型在处理中文字符时，偶尔会出现笔画粘连、错位甚至"鬼画符"。这不是 baoyu skills 的问题，而是底层生图模型的通用问题。

解决办法：逐页扫一眼，发现翻车的用 `--regenerate N` 重试。绝大多数情况下一次就正常了。如果连续三次都不行，换个风格试试——不同的风格 prompt 会影响模型的文字渲染稳定性。

### 4\. 页数在 10-18 页是甜蜜点

少于 8 页显得内容单薄，超过 20 页观众的注意力已经涣散。不同场景有不同最佳范围：

| 场景           | 推荐页数                  |
|--------------|-----------------------|
| 高管汇报 / 投资人路演 | 10-12 页（精炼，只讲最关键的事）   |
| 项目提案 / 方案汇报  | 12-15 页（有足够空间展开论证）    |
| 培训课件 / 文化宣讲  | 15-18 页（每页一个知识点，节奏舒适） |

### 5\. 风格选错 = 第一印象扣 30 分

给 CEO 做述职报告用 `sketch-notes` 手绘风——他会觉得你在开玩笑。给新人做入职培训用 `corporate` 商务风——他们会觉得你像在念规章制度。

| 观众        | 推荐风格                                   |
|-----------|----------------------------------------|
| CEO / 高管层 | `corporate`、`minimal`                  |
| 投资人       | `bold-editorial`、`corporate`           |
| 部门同事      | `sketch-notes`、`editorial-infographic` |
| 新员工 / 培训  | `chalkboard`、`sketch-notes`            |
| 技术团队      | `blueprint`、`minimal`                  |
| 客户 / 合作伙伴 | `corporate`、`notion`                   |

**判断标准很简单：如果你的观众穿西装，你就用` corporate`；如果他们穿卫衣，你就用 `sketch-notes`。**

## 七、写在最后：工具解放的不是双手，是创造力

说起来有点唏嘘。

我刚入行那会儿，带我的前辈跟我说："小王啊，干我们这行，PPT 能力就是战斗力。一份漂亮的方案，有时候比方案本身还重要。"

于是那些年我苦练 PPT 技能：怎么用母版统一格式，怎么调渐变让图表看起来更高级，怎么用 SmartArt 把一段枯燥的文字变成"视觉化表达"……我以为这是一项能让我安身立命的核心竞争力。

二十年后，AI 帮我做 PPT 比我做得还好。而且它不用学，不用练，不用熬夜。

那我这十年练的是什么？

这个问题我想了很久。后来在一次汇报结束后，我想明白了——

那次我用 baoyu-slide-deck 生成的 PPT 很漂亮，但真正让 CEO 点头的，不是那页"人才梯队建设路径"的排版有多高级。而是在生成大纲之前，我花了一整个周末思考的那件事：**在 AI 时代，一家公司到底需要什么样的人才？我们的人才观需要发生什么根本性的转变？**

这个问题，AI 帮不了我。它只能帮我把它想清楚的结果，呈现得更好看。

**当我不用再纠结"这个文本框应该放在左上角还是右下角"的时候，我终于有时间想"我要讲的这个故事，核心观点到底是什么"。当我不用再花三个小时调柱状图的配色时，我终于有精力去翻那本一直想看的书、去跟那个一直想聊的人喝杯咖啡、去把方案的底层逻辑再推敲一遍。**

baoyu skills 不是在取代你做内容。它是在帮你把"做内容"这件事里所有重复的、机械的、没有创造力的部分，全部干掉。让你把省下来的脑力和时间，花在真正值得的地方——深度思考、独到洞察、打动人心的叙事。

那个周五下午 5 点接到任务的我，之所以能在周一早上自信地走进高管会议室，不是因为 AI 帮我做了一份漂亮的 PPT——而是因为 AI 替我省下了 10 个小时的苦力活，让我能在朋友婚礼上安心地鼓掌、在健身房里痛快地流汗、在睡前安静地翻完那份一直没时间看的行业报告。

**PPT 是 AI 做的。但洞察，是我的。故事，是我的。底气，也是我的。**

```

npx skills add jimliu/baoyu-skills
```

### 与 PPT 相关的核心技能

| 技能                          | 用途                                    |
|-----------------------------|---------------------------------------|
| `baoyu-slide-deck`          | 从 Markdown 生成幻灯片（PNG 图片 + PPTX + PDF） |
| `baoyu-cover-image`         | 生成封面图（16:9，多种视觉风格可选）                  |
| `baoyu-infographic`         | 生成信息图，适合插入 PPT 的数据页                   |
| `baoyu-diagram`             | 生成流程图/架构图/组织图，适合方案类 PPT               |
| `baoyu-article-illustrator` | 为长文档自动生成配图                            |

### 常用参数速查

| 参数               | 说明       | 示例                      |
|------------------|----------|-------------------------|
| `--style`        | 视觉风格     | `--style corporate`     |
| `--slides`       | 目标页数     | `--slides 12`           |
| `--audience`     | 目标听众     | `--audience executives` |
| `--lang`         | 语言       | `--lang zh`             |
| `--outline-only` | 只看大纲不生成图 | `--outline-only`        |
| `--regenerate N` | 重生成第 N 页 | `--regenerate 5`        |

### 典型命令速查
```

# 高管述职：商务风，12 页  
/baoyu-slide-deck 年终述职.md --slides 12 --style corporate --audience executives --lang zh  
  
# 产品发布会：视觉冲击力拉满  
/baoyu-slide-deck 产品发布会.md --slides 10 --style bold-editorial --lang zh  
  
# 新人培训：手绘黑板风，轻松亲切  
/baoyu-slide-deck 入职培训.md --slides 15 --style chalkboard --lang zh  
  
# 技术方案：工程蓝图风，架构图天生适配  
/baoyu-slide-deck 技术方案.md --slides 15 --style blueprint --lang zh
```
