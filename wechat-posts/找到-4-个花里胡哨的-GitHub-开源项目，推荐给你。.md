01

**让 AI 和你一起剪时间线**

Palmier Pro 开源项目可以在时间线上生成图片和视频，也可以让 Claude、Codex 或 Cursor 连接当前项目，和你一起处理剪辑。

它从底层用 Swift 开发，目标体验参考 Premiere Pro，再重新设计 AI 进入剪辑流程的方式。

![Palmier Pro UI](https://r2.jeanjan.kdns.fr/pictures/img-21c2aa4401.png)

Seedance、Kling、Nano Banana Pro 等生成模型被放进时间线，素材生成后就留在正在编辑的项目里。

更 Palmier Pro 自带一个本地 MCP 服务。

应用打开后，Agent 可以通过本机地址读取和编辑同一条时间线。

你负责判断节奏、画面和叙事，智能体负责执行明确的操作，两边共享的是同一个项目上下文。

这里有两个使用门槛需要提前知道。

它目前只支持搭载 Apple 芯片并运行 macOS 26 Tahoe 的 Mac。

视频编辑器、MCP 服务和应用内智能体聊天采用 GPLv3 开源，生成式 AI 的处理服务没有开源。

```

开源地址：https://github.com/palmier-io/palmier-pro
```

02

**每天替你追踪真正做产品的人**

Follow Builders 是一个 Skill。

它关注真正参与研究、产品和工程实践的人，把他们在 X 上的动态、播客内容和官方博客整理成每日或每周摘要。

目前项目收获了约 5.9K 的 Star。

![](https://r2.jeanjan.kdns.fr/pictures/img-21c2aa4402.png)

默认信息源里有 26 个 AI Builder 与团队的 X 账号、6 档播客，以及 Anthropic Engineering 和 Claude Blog 两个官方博客。

摘要会保留原始链接，可以选择英文、中文或双语，方便你继续阅读真正感兴趣的内容。

把 Skill 装进 Claude Code、Codex，说一句 set up follow builders，Agent 会引导你设置推送频率和语言，并根据运行平台配置交付方式。

之后想改成每周一早上推送，或者希望摘要更短，都可以继续用自然语言调整。

```

项目地址：https://github.com/zarazhangrui/follow-builders
```

03

**专治平平无奇的 React 页面**

React Bits 当前的组件索引收录了 139 款动画和交互组件，覆盖文字动画、通用 UI、动态效果与背景。

它在 GitHub 上已经拿到约 4.38 万 Star。

![](https://r2.jeanjan.kdns.fr/pictures/img-21c2aa4403.png)

每个组件提供 JavaScript 或 TypeScript、普通 CSS 或 Tailwind 的组合版本。

你可以通过命令行工具加入项目，也可以复制源码后自行修改，再按组件提供的属性调整视觉与交互。

除了组件库，官网还准备了 Shape Magic 和 Texture Lab。

前者可以处理图形之间的内圆角并导出 SVG 或 React 代码，后者能给图片和视频添加噪点、抖动、ASCII 等 20 多种效果。

做落地页、作品集和创意产品官网时，这些小工具很容易派上用场。

想快速摆脱模板感，又不准备自己研究一整套动画系统，React Bits 值得放进前端收藏夹。

```

项目地址：https://github.com/DavidHDev/react-bits
```

04

**把听歌做成一场桌面演出**

现在的音乐播放器，大多把精力花在曲库、推荐和音质上。界面越来越规整，听歌时的氛围却有点千篇一律。

Mineradio 是一款 Windows 沉浸式音乐播放器，天气电台、歌词舞台、粒子视觉、电影镜头和 3D 歌单架全被塞进了一个桌面应用里。

![](https://r2.jeanjan.kdns.fr/pictures/img-21c2aa4404.png)

目前项目在 GitHub 上已经拿到 8000 多 Star。

打开软件后，首页会根据位置、城市和天气 mood 生成播放队列。

开始播放，画面会进入歌词与粒子联动的视觉舞台，镜头还会跟着节奏变化。碰到长播客或 DJ 曲目，项目也准备了专门的视觉模式。

![首页六卡导览](https://r2.jeanjan.kdns.fr/pictures/img-21c2aa4405.jpeg)

![导入 MP4 壁纸](https://r2.jeanjan.kdns.fr/pictures/img-21c2aa4406.jpeg)![手势控制](https://r2.jeanjan.kdns.fr/pictures/img-21c2aa4407.jpeg)  

比较吸引人的是它的 3D 歌单架。

右键唤起之后，你可以在立体界面里浏览队列。它接入了网易云音乐的账号、搜索、歌单和播客体验，也补充了 QQ 音乐搜索、登录态与音源。

```

开源地址：https://github.com/XxHuberrr/Mineradio
```
