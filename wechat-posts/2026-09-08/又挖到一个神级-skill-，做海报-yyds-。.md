用AI画一张海报，一般第一张画得非常惊艳，第二张就换成另外的风格了。

颜色深浅不一，字体也发生了变化，构图也重新搭了一遍。

单张图片还可以接受，但是要出一整组同系列的视觉效果，这样的漂移就让人很头疼。

mono-color-skill 这个开源项目，就是冲着这个来的。它在 GitHub 上目前有 2000 多个 Star。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060401.png)

它把一个主题、一句话或一张照片，转成原创的单色、受控双色印刷图像，面向海报、封面、包装、Zine 这些日常任务。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060402.png)

## 那些人值得看看这个 skill

第一种是内容创作者。公众号需要头图，小红书需要封面，播客需要方形图，每次都是不一样的。

一类是独立品牌主理人。包装贴纸、明信片、周边海报，找设计师贵，自己做又不会。

一类是设计师本人。排期很紧张，要出有印刷感的效果，但是没有时间反复试版式。

还有一部分人是学生和自由职业者。作业、简历、个人作品等，经常需要一张图，但是没有系统的练习过设计。

这些人有一个共同的特点就是：他们有想法但是缺少将想法变为图的手段。

另外一点就是，他们想要的图大都“够用就行”，并不追求专业的输出。

## 一张图，可以只是一句话的事

它不需要你把需求说得特别专业，只要把场景描述清楚就可以了。

小红书封面，3：4 竖版封面，主题为周末市集，文案放在中间。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060403.png)

播客封面，方形封面，一档聊阅读的播客，名字叫夜航船。

明信片上写着“给朋友寄一张夏天的明信片，上面有海和太阳”。

可以印在实物上也可以。包装上贴有“一罐蜂蜜的贴纸、一只陶土橙色的蜜蜂”。

Zine 内页上写着“一本关于椅子的 Zine，内页一页”。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060404.png)

想要留一些旅行纪念，就说“一张去海边的纪念海报，有灯塔和冲浪板”也可以。

这种口语化的描述它都能识别到。确定了主体、意图以及文字之后，再进行挑油墨、选版式、定留白。

最后它会给你三样东西：

一张地图、本次实际使用的提示词、一份写有印刷方式以及配色方案的配方。

即使你不懂设计术语，它也能识别出常用的词语。单色海报、双色印刷、网点照片、孔版印刷等词都包含在它的触发词中。

你讲得越详细，它选油墨、排版就越是合理。一句话说不清楚，可以再加几句场景。

## 省下的，是几套设计知识

自己画图最耗费时间的就是不断进行判断。

用什么配色，配什么字体，留白留多少，元素怎么摆，每一样都要经验。它把这些判断提前写成了规则。

单色油墨有8种，每个都标有十六进制的颜色值，不会出现这次蓝色很深、下一次蓝色很浅的现象。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060405.png)

双色配方共有九组，主墨与辅墨各司其职。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060406.png)

纸张的颜色有三种，根据主图与油墨的对比度来选择。

留白占画布 25%-55%，默认 3:4 竖版，适合手机竖屏阅读。

给你的是主题与情绪，其余的部分由规则来完成。

这套规则不需要你去记住，判断都收在背后。

## 单色双色，省钱也是风格

在印刷中，一种油墨就相当于一个印版。单色或者双色表示印版数量少，制版和印刷成本低。

对于要大规模包装、制作卡片的人来说，这是实实在在的好处。

颜色少并不等于表达少。一套双色搭配好之后，就会更容易产生出统一的识别度，印出来更有“设计感”。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060407.png)

识别度也比较好。同样的配色重复出现，就形成了一组视觉记忆点，看了几次之后就会记住。

单色印刷在实际操作中也更加方便。印版少、打样快、小批量也可以做。

当需要连续产出相同的一批物料的时候，这个优点就会更加突出。上一个配方可以继续使用，下一个封面、贴纸、海报可以保持一样的风格。

仓库中包含着 12 个原创生成示例，涵盖了各种实际应用场景。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060408.png)

沙丁鱼罐头是包装，防晒霜瓶身是包装，茶叶罐是包装，耳机盒子也是包装。

还有品牌周边系列海报、城市夜拍展竖版海报、收音机听海报等。

对于想要知道“能做成什么样子”的人来说，这个例子比文字说明更直观。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060409.png)

示例本身也是原创作品，单独受到版权保护，并且和仓库主体所使用的MIT许可分开授权。要把它用在你的作品里，注意区分这两类资产。

像茶叶罐这样的，用的是绿色网点，可以看出包装设计也能走这套流程。

![](https://r2.jeanjan.kdns.fr/pictures/img-d03b060410.png)

## 想用的话，一行命令加几个前提

它运行在 Codex 这类支持 Agent 技能的环境里。Agent 就是能读取文件、调用工具、继续往下执行任务的 AI 助手。

下载代码，把仓库放到 skills 目录下，重启客户端就可以用了。
```

git clone https://github.com/yanliudesign/mono-color-skill.git \  
	~/.codex/skills/mono-color  

```

它也符合开放标准，其它兼容Agent Skills的工具也可以直接用。

用之前有三个前提要确认。

第一、需要带图像生成的大模型。没有这个能力，它只回给你提示词。

第二、油墨种类不能超过两种。这是固定的，你要求再多也突破不了。

第三、你的照片会被"重构"。

主体身份保留，但是构图、网点、文字的位置会被重新设计。它只注重于印刷页的视觉效果，并不进行照片复制。

## 写在最后

对于经常被做成图卡住的人来说，它把设计门槛降低到了“会说一句人话”的程度。

即使你不做设计师也可以得到有印刷质感的封面和包装。单色和双色已经把成本控制在合理范围。

它把几套设计知识的判断都收进了规则，你要做的只是说清楚想要什么。

常做内容、做产品、做品牌的人用得上，偶尔想要一张海报的普通人也能上手。

有需要的可以试试看。
