# Cloudflare 又放大招：免费 Worker 也能跑 64MB 了

Cloudflare 前几天更新了 Workers 的限制。

以前，免费用户部署一个 Worker，压缩后的代码不能超过 **3MB** ，付费用户也只有 **10MB** 。

## 最新规则

现在，这个限制直接变成了：

**免费用户：64MB。**

**付费用户：也是 64MB。**

而且 Cloudflare 不再限制压缩后的大小，只检查项目解压后的大小是否超过 64MB。

![](https://r2.jeanjan.kdns.fr/pictures/img-0fe4992a02.jpeg)

这其实是一个相当大的变化。

如果你没听说过 Cloudflare Workers，可以简单把它理解成：**Cloudflare 免费送给你的一台“小服务器”。**

它最大的特点，就是你不用买 VPS，也不用安装 Linux、Nginx，更不用考虑服务器放在哪里。

写好程序，点一下部署，它就运行在 Cloudflare 全球的网络上。

更重要的是，它还有一个相当慷慨的免费额度。目前免费版每天可以处理 **10 万次请求** 。对于个人项目和一些小工具来说，已经完全够用了。

## 那它能干什么？

其实非常多。

比如你可以部署一个**临时邮箱** ，用自己的域名收邮件；也可以做一个**短链接服务** ，把很长的网址变成自己的短网址。

还可以搭建 Pastebin、在线剪贴板、图床、文件分享、RSS 服务、API 中转、Telegram Bot，甚至是一个完整的小网站。

Cloudflare 自己还提供了数据库 D1、对象存储 R2、KV 存储等服务。换句话说，一个小型网站需要的服务器、数据库和文件存储，Cloudflare 基本都给你准备好了。

过去 Workers 有一个很明显的问题，就是**装不下太大的程序** 。

特别是一些依赖比较多的开源项目，代码本身可能没多大，但是安装几个软件包以后，很容易撞上 3MB 的限制。

现在直接放宽到 64MB，相当于一下增加了二十多倍。

很多以前只能放在 VPS 上运行的小工具，现在都有机会搬到 Workers 上。
