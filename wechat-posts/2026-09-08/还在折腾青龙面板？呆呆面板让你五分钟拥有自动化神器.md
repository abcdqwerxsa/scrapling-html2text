> 定时任务管理、脚本托管、多语言支持、18 种推送渠道、订阅管理、双因素认证……青龙面板能做的它都行，Go + Vue3 架构更轻更现代。今天介绍一款开源的轻量级定时任务管理面板——呆呆面板（Daidai Panel）。

## 一、先聊两句：青龙面板是什么，呆呆面板又是什么？

玩过自动签到的朋友大概率听说过**青龙面板** ——老牌定时任务管理平台，生态成熟但部署重、界面老、资源占用大。而**呆呆面板** （Daidai Panel）是后起之秀，采用 Go 1.25 + Vue 3 + SQLite 纯 Go 架构，`CGO_ENABLED=0` 编译无需任何 C 依赖，Docker 一键部署，开箱即用。

![呆呆面板仪表盘](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c02.jpeg)

呆呆面板仪表盘

简单说：**青龙面板能做到的，呆呆面板基本都能做到，而且更轻、更快、界面更现代。** 环境变量格式完全兼容青龙，订阅参数对应青龙 `ql repo` 的第 2/3/4 个参数，迁移成本几乎为零。

## 二、核心功能：一个面板搞定定时任务全流程

### 01 定时任务管理

标准 Cron 表达式调度，支持常用时间规则快捷选择、任务启用/禁用切换、手动触发执行。更支持超时控制与重试机制、**前后置钩子** （任务依赖链）、多实例并发控制、定时停止功能。

![定时任务管理界面](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c03.jpeg)

定时任务管理界面

### 02 脚本文件管理

内置 Monaco Editor 在线代码编辑器（和 VS Code 同款），支持语法高亮、文件创建/重命名/删除、拖拽移动、脚本版本管理、调试运行与实时日志输出。**多语言支持** ：Python、Node.js（含 `.js` / `.mjs`）、Shell、TypeScript、Go。

![脚本管理界面](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c04.jpeg)

脚本管理界面

### 03 执行日志

SSE 实时日志流推送，执行状态追踪（成功/失败/超时/手动终止），执行耗时统计，日志自动清理策略。看日志不用刷新页面，实时滚动输出。

![执行日志界面](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c05.jpeg)

执行日志界面

### 04 环境变量

安全存储敏感配置，变量值脱敏显示，分组管理与拖拽排序。**批量导入导出完全兼容青龙格式** ，从青龙迁移过来直接导入即可。任务执行时自动注入环境变量。

![环境变量界面](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c06.jpeg)

环境变量界面

### 05 订阅管理

Git 仓库自动拉取，定期同步（Cron 调度），SSH Key / Token 认证。**白名单/黑名单/依赖规则过滤** ，完全对应青龙 `ql repo` 的第 2/3/4 个参数：

  * • **白名单** ：命中的文件落盘并建成定时任务
  * • **依赖规则** ：命中的文件拉到脚本目录供主脚本调用，但不建成任务
  * • **黑名单** ：对白名单和依赖规则都生效
  * • 分隔符 `,` 和 `|` 均可，匹配方式是**子串包含** 而非正则
  * ![订阅管理界面](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c07.jpeg)

订阅管理界面

### 06 依赖管理

可视化安装/卸载 Python (pip) 和 Node.js (npm) 依赖，不用进命令行敲 pip install，面板里点一下就装好了。

![依赖管理界面](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c08.jpeg)

**18 种主流推送渠道** ：Bark、Telegram、Server酱、企业微信、钉钉、飞书等全覆盖。支持任务执行结果通知、系统事件告警、自定义推送模板。跑完任务自动推消息，成功失败一目了然。

![通知渠道界面](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c09.jpeg)

App Key / App Secret 认证，支持第三方系统对接。配合官方 APP 客户端，手机上也能管理定时任务。

**双因素认证 (2FA / TOTP)** 、IP 白名单、登录日志、多设备会话管理（可配置网页端 / APP 端最大会话数）。安全性比青龙面板高出一截。

一键备份与恢复（含视图数据），支持每天/每周/每月定时备份。备份文件存在 `Dumb-Panel/backups/` 目录，迁移方便。

### 11 系统监控

实时 CPU / 内存 / 磁盘监控，任务执行趋势统计。面板自己的资源消耗一目了然。

**此外** ，呆呆面板还支持面板标题与图标自定义、脚本内调用面板能力（发通知、写回环境变量、触发其他任务）等高级功能。

## 三、部署教程：Docker 五分钟搞定

呆呆面板推荐使用 Docker 部署，默认端口 **5700** ，核心数据目录为 `Dumb-Panel`。支持 Docker（多架构）、Windows 单机版、Android Magisk 模块三种部署方式。

![Docker 部署流程示意图](https://r2.jeanjan.kdns.fr/pictures/img-d304e73c12.jpeg)

Docker 部署流程示意图

### 方式一：Docker Compose（推荐）

创建 `docker-compose.yml`：
```

name: daidai-panel  
   
services:  
  daidai-panel:  
    image: ${DAIDAI_PANEL_IMAGE:-linzixuanzz/daidai-panel:latest}  
    container_name: daidai-panel  
    restart: unless-stopped  
    ports:  
      - "5700:5700"  
    volumes:  
      - ./Dumb-Panel:/app/Dumb-Panel  
    environment:  
      - TZ=Asia/Shanghai  
      - CONTAINER_NAME=daidai-panel  
      - IMAGE_NAME=${DAIDAI_PANEL_IMAGE:-linzixuanzz/daidai-panel:latest}  
      - WATCHTOWER_HTTP_API_PERIODIC_POLLS=true
```

一键启动：
```

docker compose up -d
```

> **Compose 设计要点** ：
> 
>   1. 1\. 面板容器只挂业务数据目录，`docker.sock` 只给 Watchtower
>   2. 2\. `DAIDAI_PANEL_IMAGE` 同时控制镜像和 `IMAGE_NAME`，切换标签只改一处
>   3. 3\. `LITEPAN_CORS_ORIGINS` 表示你的反代域名和内网访问地址
> 

### 方式二：docker run
```

docker network create daidai-panel-net  
WATCHTOWER_API_TOKEN=daidai-panel-watchtower-token  
   
docker run -d --pull=always \  
  --name daidai-panel \  
  --network daidai-panel-net \  
  --restart unless-stopped \  
  -p 5700:5700 \  
  -v "$(pwd)/Dumb-Panel:/app/Dumb-Panel" \  
  -e TZ=Asia/Shanghai \  
  -e CONTAINER_NAME=daidai-panel \  
  -e IMAGE_NAME=linzixuanzz/daidai-panel:latest \  
  -e LITEPAN_CORS_ORIGINS=https://litepan.yourdomain.com,http://192.168.31.91:5700 \  
  linzixuanzz/daidai-panel:latest
```

### 方式三：Windows 单机版

不用 Docker，下载即用：

  1. 1\. 去 GitHub Release[3] 下载 `daidai-windows-amd64.zip`
  2. 2\. 解压到任意目录（建议路径无空格、无中文，如 `D:\daidai-panel`）
  3. 3\. 双击 `start.bat` 启动服务
  4. 4\. 浏览器访问 `http://localhost:5700`，首次进入创建管理员账号

> 如需调度 Python / Node.js 脚本，需自行安装 Python 3.10+ 和 Node.js 20 LTS 并勾选 "Add to PATH"。

### 方式四：Android Magisk 模块（Root 手机）

在已 Root 的安卓设备上直接运行，无需 Docker、无需 Termux：

  * • **支持** ：Magisk v24.0+ / KernelSU / APatch；Android 6.0+（建议 8.0+）；仅 `arm64`
  * • **默认访问** ：`http://127.0.0.1:5700`
  * • **Alpine 版** （默认）：体积小、装得快，磁盘 ≥1.5 GB
  * • **Debian 版** ：需要跑 glibc 预编译产物时选，磁盘 ≥2.5 GB

### 镜像标签怎么选？

| 标签            | 基础系统   | Python | 工具档位 | 适用场景              |
|---------------|--------|--------|------|-------------------|
| `latest`      | Alpine | 3.12   | 精简   | **默认选它** ，大多数场景够用 |
| `latest-full` | Alpine | 3.12   | 完整   | 需要跑 Go 任务或编译依赖    |
| `latest-3.10` | Alpine | 3.10   | 精简   | 脚本依赖 Python 3.10  |
| `debian`      | Debian | 3.12   | 精简   | 需要 glibc 环境       |
| `debian-full` | Debian | 3.12   | 完整   | Debian + Go 任务    |

> 自 v3.0.0 起，**Go 任务必须使用` latest-full` 或 `debian-full`**。

切换标签只需一行：
```

DAIDAI_PANEL_IMAGE=linzixuanzz/daidai-panel:latest-full docker compose up -d
```

### 数据目录结构

保留 `Dumb-Panel` 目录 = 保留整个面板状态：
```

Dumb-Panel/  
├── daidai.db          # SQLite 数据库  
├── .jwt_secret        # JWT 密钥  
├── panel.log          # 运行日志  
├── deps/              # Python / Node.js 依赖  
├── scripts/           # 脚本文件  
├── logs/              # 任务日志  
└── backups/           # 数据备份
```

## 四、使用指南：从部署到自动签到

### 第 1 步：访问后台

浏览器打开 `http://你的IP:5700`，首次进入创建管理员账号。

### 第 2 步：添加环境变量

进入「环境变量」页面，手动添加或**批量导入** （兼容青龙格式）。比如签到脚本的 Cookie、Token 等敏感信息都放这里，任务执行时自动注入。

### 第 3 步：添加脚本

两种方式：

  * • **手动创建** ：在「脚本管理」里新建文件，用内置 Monaco Editor 直接写代码
  * • **订阅拉取** ：在「订阅管理」里添加 Git 仓库地址，自动拉取脚本并创建定时任务

### 第 4 步：创建定时任务

在「定时任务」页面新建任务，填写 Cron 表达式（也支持常用规则快捷选择），选择脚本文件。可选配置超时时间、重试次数、前后置钩子。

### 第 5 步：配置通知

进入「通知渠道」，选择你用的推送平台（Bark、Telegram、企业微信、钉钉、飞书等 18 种），填入 Token。任务执行完毕后自动推送结果。

### 第 6 步：查看日志

任务执行后，在「执行日志」里查看 SSE 实时日志流，支持成功/失败/超时/手动终止状态追踪。

### 第 7 步：管理依赖

如果脚本需要第三方库，在「依赖管理」里可视化安装 pip / npm 包，不用进终端。

### 第 8 步：运维命令 ddp

容器内置 `ddp` CLI 工具，覆盖运维全场景：
```

# 查看状态  
docker exec -it daidai-panel ddp status  
   
# 重置密码（忘了密码也不怕）  
docker exec -it daidai-panel ddp reset-password admin NewPass123  
   
# 清理 7 天前的日志  
docker exec -it daidai-panel ddp clean-logs 7  
   
# 创建备份  
docker exec -it daidai-panel ddp backup create --name nightly  
   
# 手动执行任务  
docker exec -it daidai-panel ddp task run 12  
   
# IP 白名单锁住了？这样解锁  
docker exec -it daidai-panel ddp ip-whitelist clear
```

## 六、FAQ

**Q：从青龙面板迁移麻烦吗？**

不麻烦。环境变量支持批量导入导出且完全兼容青龙格式，订阅管理的白名单/黑名单/依赖规则对应青龙 `ql repo` 的第 2/3/4 个参数。导出青龙的环境变量，在呆呆面板导入即可。

**Q：支持哪些 CPU 架构？**

支持 `linux/amd64`、`linux/arm64`、`linux/386`、`linux/arm/v7`。树莓派、Oracle ARM 云、Apple Silicon、x86 服务器、NAS 都能跑。

**Q：Go 任务怎么跑？**

自 v3.0.0 起，Go 任务必须使用 `latest-full` 或 `debian-full` 镜像。精简版不含 Go 编译链。

**Q：忘了密码怎么办？**
```

 docker exec -it daidai-panel ddp reset-password admin NewPass123
```

**Q：如果 IP 白名单把自己锁在外面怎么办？**
```

 docker exec -it daidai-panel ddp ip-whitelist clear
```

**Q：可以商用吗？**

MIT License，可以商用，无需授权。

**Q：面板更新怎么操作？**

进面板「系统设置」→「概览」→「检查系统更新」→「立即更新」。Docker 精简版由 Watchtower 自动拉取重建容器，二进制部署自动下载替换。

**Q：不想自动更新怎么办？**

删除 `docker-compose.yml` 中的 `watchtower` 服务、`labels`、`PANEL_UPDATE_MANAGER=watchtower` 和 `WATCHTOWER_HTTP_API_*`，然后手动执行：
```

docker compose pull  
docker compose up -d
```

**Q：反向代理怎么配？**

关键两点：代理目标是宿主机端口（如 `127.0.0.1:5700`），不是容器内 `5701`；SSE 日志流需要 `proxy_buffering off`。详见项目 README 的 Nginx 配置示例。
