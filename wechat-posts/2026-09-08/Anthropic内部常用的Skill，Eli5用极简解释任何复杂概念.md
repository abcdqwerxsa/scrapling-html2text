# Anthropic内部常用的Skill，Eli5用极简解释任何复杂概念

**作者**: 赛博大福
**发布时间**: 2026-09-01 07:30

当大家在被各种 Skill 的神奇产出震撼时，我也一度觉得：Skill 就应该足够复杂，必须拆解复杂工作流，包含详细步骤、分支逻辑、工具调用和检查清单，才称得上一个“好 Skill”。

直到最近，我在 X 上刷到 Anthropic 工程师 Thariq 分享的一个 Skill。据说，这个 Skill 在 Anthropic 内部相当流行。我当时心想：这可了不得，到底是什么 Skill？

![](https://r2.jeanjan.kdns.fr/pictures/img-ec17ca8a01.jpeg)

结果打开 SKILL.md 一看，好家伙，核心指令竟然只有一句话！短短 20 个词，却能让 AI 从“输出一大段文字”，切换成“做一张图文”，用简单直观的逻辑把复杂问题讲明白。

这个 Skill 叫 **ELI5** 。

**ELI5** 是 “Explain Like I’m 5” 的缩写，直译就是“像给五岁小孩解释一样”。这里的“5”并不代表真的要用幼儿语言解释，而是提醒 AI：别一上来堆术语，先把事情讲清楚。![](https://r2.jeanjan.kdns.fr/pictures/img-ec17ca8a02.png)

它的核心指令非常简单：

把我当成一个对这个话题完全不懂的人，用大图、少字的 HTML 页面给我讲明白。

也就是说，它给 AI 设定了三个限制：

  
面向一个完全没有背景知识的人

  
不只输出文字，而是制作一个 HTML 页面（html格式真的是最好用的呈现形式）

  
用大图、少量文字和清晰结构来解释

我的个人测试是普通回答和 **ELI5** 最大的区别，不是信息量变少了，而是理解路径变清楚了。

做完之后，我就知道它强在哪了！以前问 AI 复杂问题，它默认长篇大论，新词一堆，越看越懵。

**ELI5** 就是逼它换种方式交作业：大图、少字、一步步顺着讲。

所以，如果你也经常被“专业术语”劝退，或者总在“给人讲不明白、自己学不懂”之间反复横跳，不妨试试把问题交给 **ELI5** 。

学新领域，先把复杂问题“降维”：

遇到陌生概念，先让它用最简单的方式，帮你搭一张认知地图；等你知道这件事大概是怎么回事，再回头去啃细节。

同一份内容，换个听众讲一遍：

一份技术文档，最难的往往不是讲给工程师，而是拿去和老板沟通。你可以试试 **ELI5** 的“小白模式”：把术语换成人话，把复杂过程讲简单，老板没准立马就懂了。

帮家人翻译专业信息：

体检报告、法律条文，都可以先让它翻译成大白话，变成爸妈听得懂、记得住的话，很多事情就不用解释半天了。

把知识讲成孩子爱听的故事：

科学、历史、数学原理，换成故事、比喻和生活场景来讲，孩子更容易理解，也更愿意继续提问。

把复杂的内容拆开，把抽象的概念画出来，把一大段文字压缩成几句人话。

这大概就是 **ELI5** 最有意思的地方。
